# Historical nRF5340 E83 FR1 flashing record

> **Historical provenance only.** This document records a former FR1 package
> shape. It is not an active release candidate, current package input, or
> supported public release asset.

## Historical target and images

This historical package was for the **nRF5340 receiver** (Ebyte E83 module on
the custom nRF5340DK-style board). It contained two image files that had to be
flashed together as one versioned tuple:

| File | Role | Flash order |
|------|------|-------------|
| `merged.hex` | Application core (cpuapp) | 1 |
| `merged_CPUNET.hex` | Network core (cpunet, hci_ipc link layer) | 2 |

Do not mix these files with images from a different version or target.
The pair is one release tuple; flashing one half without the other leaves
the device in an unsupported state.

## Historical flash order

1. `merged.hex` (cpuapp)
2. `merged_CPUNET.hex` (cpunet)

Historical normal flashing through the repository helper (`fw-flash-5340`)
programmed firmware address ranges and preserved settings and bonds. A
destructive clean-state or recovery procedure (for example a full chip erase)
was a separate, target-specific step; it was never implied by this package.
