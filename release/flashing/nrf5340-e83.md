# Flashing the nRF5340 E83 release candidate

## Target and images

This package is for the **nRF5340 receiver** (Ebyte E83 module on the
custom nRF5340DK-style board). It contains two image files that must be
flashed together as one versioned tuple:

| File | Role | Flash order |
|------|------|-------------|
| `merged.hex` | Application core (cpuapp) | 1 |
| `merged_CPUNET.hex` | Network core (cpunet, hci_ipc link layer) | 2 |

Do not mix these files with images from a different version or target.
The pair is one release tuple; flashing one half without the other leaves
the device in an unsupported state.

## Flash order

1. `merged.hex` (cpuapp)
2. `merged_CPUNET.hex` (cpunet)

Normal flashing through the repository helper (`fw-flash-5340`) programs
firmware address ranges and preserves settings and bonds. A destructive
clean-state or recovery procedure (for example a full chip erase) is a
separate, target-specific step; it is never implied by this package.
